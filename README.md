# 部活カレンダー（Vercel版）

## 構成
- `public/index.html` … 画面
- `api/data.js` … サーバー側（パスワード判定・データ保存）。依存パッケージなし

## 公開の3段階
- 誰でも: 練習日と時間のみ
- 部員（登録した表示名＋パスワードでログイン）: 日ごとの参加者の名前・男女別人数（理由は本人と管理者のみ）
- 管理者（管理者パスワード）: 全員の出欠・理由、練習日と名簿の編集

## デプロイ手順
1. このフォルダをGitHubにpush（または `npx vercel` で直接デプロイ）
2. Vercelでプロジェクトをインポート（Framework Preset は「Other」、設定は変更不要）
3. プロジェクトの Storage タブ → Marketplace から **Upstash Redis（無料枠）** を作成して接続
   （環境変数 `KV_REST_API_URL` / `KV_REST_API_TOKEN` などが自動で入ります）
4. Settings → Environment Variables に次の2つを追加
   - `ADMIN_PASSWORD` … 管理者パスワード（長めに）
   - `MEMBER_CODE` … 部員に共有するパスコード
5. Redeploy（環境変数を追加した後は再デプロイが必要）

## 運用メモ
- 部員は初回に「部員パスコード＋表示名＋パスワード」で自分で登録します。登録した端末は自動でログインされます
- 部員パスコードは登録時のみ使います。漏れたら環境変数を変えて再デプロイしてください
- パスワードを忘れた部員は、管理画面で削除すると同じ表示名で再登録できます
- ADMIN_PASSWORD を変えると、全員の端末のログイン記憶が無効になります

## 仕様メモ
- 練習開始後に出欠を変更・取り消した部員は、一覧で赤く表示されます（時刻は日本時間）。一度付いた印は外れません
- 連続欠席は、終了した練習を日付順に見て「不参加」または未回答なら+1、参加・遅刻・早退なら0に戻る方式で、管理画面に表示されます（登録前の練習は数えません）
- 練習の開始・終了時刻は日本時間（JST）として扱います
- 管理者は、練習日の画面の「回答を編集（管理者）」から全員の出欠を変更・取り消しできます（管理者による修正では赤い印は付きません）
- 開始後に変更した人の赤い表示は部員にも見えますが、変更した時刻は管理者にのみ表示されます
